# Glossary

Danish terms are used in the UI; code uses the English name.

| Danish | Code | Meaning |
|---|---|---|
| Bord | `Table` | The room: 4 seats, a host, table chat, a type (open/password/private). Hosts any number of games in sequence. |
| Spil | `Game` | One game of hjerterfri, played until someone reaches the end score (default 100). |
| Runde | `Round` | One deal: the pass (if any) plus 13 tricks. |
| Stik | `Trick` | Four cards, one per seat; the winner leads the next. |
| Vært | host | The player who created the table and controls its settings. |
| Puf | nudge | An invitation to a friend to join a specific table; accepted or declined. |
| Bot | bot | A computer player in a seat. Cannot vote. |
| Afstemning | vote | Decision among connected humans when a player is absent: wait / bot takes over / end game. |
